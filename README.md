# Blog Mololo — Studio Média Culturel en Ligne

Bienvenue sur le projet du site vitrine et média de **Blog Mololo**, un studio média culturel en ligne célébrant les cultures contemporaines africaines et leur diaspora.

Projet conçu et développé selon la méthodologie d'ingénierie **MOKILI Framework V1.1** (Moteur Spécialisé Site Vitrine V1.0).

---

## 🎨 Identité Visuelle & Vibe
- **Direction Artistique :** Inspirée de la ligne éditoriale contemporaine et percutante de [Pan African Music (PAM)](https://pan-african-music.com), magnifiée par l'ADN graphique de Mololo.
- **Charte Graphique :**
  - **Rouge Écarlate Électrique :** `#e01a31`
  - **Crème Chaleureux / Toile :** `#fff1d9`
  - **Noir Profond :** `#000000`
  - **Blanc Pur :** `#ffffff`
- **Typographie :** `Exo` (corps & titrailles vibrantes) & `Unbounded` (chiffres & badges de formats).
- **8 Formats Médias :**
  - *Mololo Session* (live sessions acoustiques et studio)
  - *Mololo Club* (culture clubbing, soirées & sound systems)
  - *Mololo Radar* (dénicheur de pépites et talents émergents)
  - *Mololo News* (dépêches d'actualité culturelle et chroniques)
  - *Mololo+* (entretiens immersifs et exclusivités)
  - *Mololo Episode* (podcasts et séries documentaires)
  - *Mololo Playlist* (sélections musicales curatées)
  - *Mololo Original* (créations et productions originales)

---

## 🚀 Stack Technique
- **Framework :** [Astro v5](https://astro.build) (Génération Statique SSG haute performance)
- **Langage :** TypeScript (typé strictement)
- **Styles :** Tailwind CSS avec Design Tokens Mololo
- **Architecture :** Niveau A MOKILI (100% statique, 0 backend serveur superflu)
- **Hébergement cible :** H01 — Static / Edge (Cloudflare Pages, Vercel, Netlify ou VPS MOKILI statique)

---

## 🛠️ Commandes Locales

```bash
# Installation des dépendances
npm install

# Démarrer le serveur de développement local
npm run dev

# Compiler le site statique pour la production
npm run build

# Prévisualiser le build de production localement
npm run preview
```
